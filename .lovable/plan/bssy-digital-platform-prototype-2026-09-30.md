# BSSY Digital Platform Prototype

## Goal
Build a polished, responsive, frontend-only civic operations prototype using the supplied synthetic records and lifecycle journey.

## Experience
- Create the persistent BMC-styled navigation shell, compact header, demo role switcher, language selector, notifications, and mobile menu.
- Build every requested navigation destination as a useful in-app view, sharing one consistent mock dataset and visible prototype disclaimers.
- Make the eight-step journey prominent and clickable, with linked work order, Sanstha, worker, attendance, evidence, grievance, performance, and recommendation records.
- Add practical local interactions: filtering, drawers, status decisions, grievance submission/lookup, notifications, role switching, export preview, and action confirmations.

## Visual direction
- Use the specified civic navy, institutional blue, warm neutral surfaces, terracotta accent, restrained shadows, thin borders, and accessible status colors.
- Prioritize executive summaries and readable operations detail; adapt tables into scrollable or card-like layouts on smaller screens.
- Use schematic visuals only for GIS, evidence, QR, charts, and integration states, with explicit synthetic/illustrative labels.

## Technical approach
- Keep all state local to the browser; add no authentication, backend, database, map, messaging, payment, or AI connection.
- Organize reusable UI, seeded data, and the main route into focused modules while keeping the prototype lightweight.
- Add route-specific metadata and preserve the existing TanStack application structure.
- Verify the main journey and responsive rendering in the live preview, then resolve any build/runtime errors.
